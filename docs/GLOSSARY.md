# AegisLoop Glossary

- **Purple-team workflow:** a coordinated learning loop combining test activity and defensive validation.
- **Scenario:** a predefined, bounded test fixture.
- **Finding:** the educational issue surfaced by a scenario.
- **Evidence:** structured fixture data explaining why the finding was produced.
- **Mitigation:** an allowlisted defensive change represented by a rule or educational diff.
- **Retest:** re-evaluation of a named assertion after mitigation.
- **Assertion:** a specific, testable condition with a pass/fail outcome.
- **Simulation mode:** deterministic fixture execution with no external target.
- **Local isolated lab:** optional local Docker environment with a toy vulnerable target.
- **Agent path:** UI visualization of workflow stages; not proof of live traffic.
- **State machine:** the allowed lifecycle of a run.
- **ADR:** Architecture Decision Record, documenting a decision and its trade-offs.
